## 1. 帯展開座標系（Belt Unfolding）

### 1.1 コンセプト

2次元のコース形状を「1本の帯」に展開し、レース展開をシンプルなY-X空間で表現する。

```
実コース（2D楕円）           帯空間（展開後）
  ┌─────────┐                Y軸: スタート(0) → ゴール(1200m)
  │  カーブ  │     ─→        X軸: イン(-12.5m) ↔ アウト(+12.5m)
  │  3角-4角 │                
  └─────────┘                レース展開 = 各馬の(Y(t), X(t))の時系列
```

### 1.2 座標変換

| 区間 | Y範囲 | 特性 |
|------|-------|------|
| 向正面（直線） | 0m 〜 348m | 補正なし。vy = v |
| 3角〜4角（カーブ） | 348m 〜 788m | 距離補正あり。vy = v × R/(R+x) |
| 最終直線 | 788m 〜 1200m | 補正なし。vy = v。急坂あり |

カーブ区間の距離補正:
- 曲率半径 R = 300m（中心線）
- イン最内(x=-12m): 実距離422.4m（中心線比 -17.6m）
- アウト最外(x=+12m): 実距離457.6m（中心線比 +17.6m）
- **最内vs最外の距離差: 35.2m → 約2.05秒の差**（平均速度17.1m/sで換算）

### 1.3 帯空間の運動方程式

```
Y方向（前進）: m·(d²y/dt²) = F_propulsion·cos(θ) - F_drag - F_slope(y)
X方向（横移動）: m·(d²x/dt²) = -F_propulsion·sin(θ) + F_centrifugal(y,x,v) - F_crowd(x,t)
```

- θ: 推進力のうち横方向に振り向ける角度
- F_centrifugal: カーブ区間のみ発生。mv²/(R+x)
- F_crowd: 馬群からの圧力（他馬の位置に依存）
- F_slope: 高低差による抵抗（最終直線の急坂）

## 2. コスト関数の4因子分解

帯空間での位置(x)と時間(t)に対するコスト:

$$\text{Cost}(x, t) = C_{dist}(x) \times C_{cf}(x, v) \times C_{crowd}(x, t) \times C_{turf}(x, d)$$

### 2.1 距離効果 C_dist(x)

カーブ区間で内側ほど実距離が短い。

$$C_{dist}(x) = \frac{R + x}{R}$$

| x位置 | C_dist | 距離差 |
|-------|--------|-------|
| -12m (最内) | 0.960 | -17.6m |
| -8m | 0.973 | -11.7m |
| 0m (中央) | 1.000 | ±0m |
| +8m | 1.027 | +11.7m |
| +12m (最外) | 1.040 | +17.6m |

**推定方法**: 幾何学的に計算。データ不要。

### 2.2 遠心力コスト C_cf(x, v)

カーブ区間でインを走ると遠心力が大きく、横方向の力に推進力を割かねばならない。

$$C_{cf}(x, v) = 1 + \alpha \cdot \frac{v^2}{R + x}$$

- α: 遠心力が前進効率に与える影響係数（推定対象）
- v = 17.1 m/s のとき、遠心力加速度 ≈ 0.94〜1.01 m/s²

**注意**: イン側ほど遠心力が大きい → C_cfがイン側で大きくなる → 距離メリットを一部相殺。

**推定方法**: 枠番効果から距離効果・馬群圧力・芝状態を引いた残差。

### 2.3 馬群圧力 C_crowd(x, t)

イン側は馬群が密集し、進路がブロックされるリスクがある。

**EDAの知見（新潟直線1000mより）**:
- カーブが存在しない直線コースでも、イン枠はアウト枠より勝率が大幅に低い
- 上位人気(1-3番人気)に統制しても: イン勝率13.6% vs アウト勝率22.1%
- → 馬群圧力だけでも約8.5ptの勝率差が生じる
- ただし新潟直線には芝の状態差の交絡があり（外側の芝が良い）、純粋な馬群圧力はこれより小さい可能性

**注意**: 新潟直線では馬群圧力と芝状態が分離困難。中京の枠番効果から総合的に推定する方が堅実。

### 2.4 芝状態 C_turf(x, d)

開催が進むとイン側の芝が傷み、イン走行のコストが増加する。

**EDAの重要発見 — 開催前半vs後半でのイン有利度変化**:

| コース | 前半イン有利度 | 後半イン有利度 | 変化 |
|--------|-------------|-------------|------|
| **阪神** | +7.6pt | -1.1pt | **-8.7pt** |
| **中京** | +2.8pt | -0.1pt | **-2.9pt** |
| 中山 | -3.0pt | -1.9pt | +1.1pt |
| 小倉 | -0.6pt | -0.3pt | +0.3pt |

**中京の月別イン有利度（上位人気、勝率ベース）**:
- 1月: +26.2pt（開催序盤、芝が新鮮）
- 3月: +5.4pt（高松宮記念の時期、芝が荒れている）
- 7月: +20.0pt（夏開催、芝を張り替えた後？）
- 12月: +15.0pt

→ **高松宮記念(3月末)はイン有利度が最も小さい時期**。芝の荒れがインのメリットを大幅に削っている。

**推定方法**: 同一コース内の月別（開催時期別）枠番効果の変化から推定。

## 3. 4因子の関係性まとめ

```
インを走るメリット:
  (+) 距離が短い（C_dist < 1.0）     ... 幾何学的に確定、最大2秒の効果

インを走るデメリット:
  (-) 遠心力が大きい（C_cf > 1.0）   ... αを推定する必要あり
  (-) 馬群に包まれる（C_crowd > 1.0） ... 頭数・展開依存
  (-) 芝が荒れている（C_turf > 1.0）  ... 開催時期依存

最適な走行ライン = 4因子のトレードオフの結果
```

### 各因子の推定戦略

| 因子 | 推定方法 | データ源 | 信頼度 |
|------|---------|---------|--------|
| C_dist | 幾何学計算 | コース仕様 | ◎ 確定 |
| C_turf | 月別×枠番の交互作用 | 中京+阪神（開催進行の明確な影響あり） | ○ 良好 |
| C_crowd | 多頭数レースの全コース共通成分 | 全コース芝1200m | △ 芝との分離が課題 |
| C_cf | 残差: 全体 - dist - turf - crowd | 上記すべて | △ 他3因子の精度に依存 |

## 4. ソフトラベル設計

### 4.1 問題意識
着順は離散値(1着, 2着, ...)だが、3着と4着の差が0.0秒（鼻差）の場合、実力的には同等。
ハードラベル(3着以内=1, それ以外=0)は情報を捨てている。

### 4.2 ソフトラベルの定義

教師信号を着差に基づく連続値にする:

```python
def soft_label(rank, time_diff_from_3rd):
    """
    rank: 着順
    time_diff_from_3rd: 3着との着差（秒）。3着より前ならマイナス。
    """
    if rank <= 3:
        return 1.0
    elif time_diff_from_3rd <= 0.1:  # 鼻差〜クビ差（0.0〜0.1秒）
        return 0.8
    elif time_diff_from_3rd <= 0.3:  # 半馬身〜1馬身差
        return 0.5
    elif time_diff_from_3rd <= 0.6:  # 1〜3馬身差
        return 0.2
    else:
        return 0.0
```

### 4.3 メリット
- 学習データの有効活用（4着以降も実力の指標として使える）
- 「荒れるレース」での学習安定性向上
- NDCG@3との整合性（ランキング品質の評価）

## 5. Model 1 が「荒れ」を説明できるポイント

高松宮記念が荒れやすい理由を物理モデルで説明する試み:

1. **馬場状態の変動**: 良→重で5.5秒差。重馬場への適性が人気と一致しない馬がいる
2. **芝状態の劣化**: 3月末は芝が最も荒れた状態。イン有利がほぼ消失 → 人気薄のアウト馬にもチャンス
3. **18頭フルゲートの馬群圧力**: 多頭数→インが使えない→距離ロスが大きい
4. **スプリントの展開依存性**: 1200mは6ハロンしかなく、1つのミス（出遅れ、包まれ）がそのまま着順に直結
5. **遠心力×速度の非線形性**: G1レベルの高速巡航ではv²で遠心力が効く → 微小な位置取り差が拡大

→ これらを物理モデルで定量化できれば、「なぜ荒れたか」を事後的に説明し、「荒れやすい条件」を事前に予測できる。

## 7. Physics-Informed Parameter Learning（物理×学習ハイブリッド）

### 7.1 設計思想

モデルの**構造（力の方程式、因果関係）**は物理で固定し、**一部のパラメータだけ**をデータから学習する。
これにより:
- 物理的に解釈可能なモデルを維持
- フリーパラメータを最小限（5個）に抑え、オーバーフィッティングを回避
- 「なぜそう予測したか」を各パラメータの値で説明可能

### 7.2 パラメータの3層分類

```
Layer 1: 物理で確定（学習不要）
  - 距離効果 C_dist(x) = (R+x)/R
  - 遠心力の式 F_cf = mv²/(R+x)
  - 坂の勾配プロファイル（コース仕様から）
  - コース区間の長さ（向正面348m, カーブ440m, 直線412m）

Layer 2: データから統計推定（回帰・集計）
  - 遠心力コスト係数 α（枠番分析から）
  - 芝状態劣化関数 C_turf(x, d)（開催時期分析から）
  - 馬場状態補正係数（良/稍重/重/不良のタイム差から）
  - 馬固有の速度能力（過去タイムから）

Layer 3: 学習で仮定（5パラメータ、NDCG@3で最適化）
  - β_cohesion: 群凝集力の強さ
  - β_aniso: 群凝集の異方性（前方追従 vs 側方回避の比率）
  - β_experience: 出走経験による群凝集の減衰率
  - β_jockey: 騎手スキルの走行圧感知への変換係数
  - β_draft: ドラフト効果の強さ（前方馬による空気抵抗軽減率）
```

### 7.3 各パラメータの物理的意味と探索範囲

| パラメータ | 物理的意味 | 探索範囲 | 制約 |
|-----------|-----------|---------|------|
| β_cohesion | 群凝集力(N) | 0〜5.0 | 正値。大→群れに留まる |
| β_aniso | 前方/側方の力比 | 0.5〜5.0 | >1で前方追従が強い |
| β_experience | 出走n回あたりの減衰率 | 0.9〜1.0 | <1で経験豊富な馬は群凝集が弱い |
| β_jockey | 騎手スキル変換係数 | 0〜2.0 | 大→上手い騎手が有利 |
| β_draft | ドラフト効果(%) | 0〜30% | Stokes論文では10-20%程度 |

### 7.4 生物学的仮説と対応

**仮説1: 競馬レースは馬にとって群衆逃避行動である**

```
→ β_cohesion > 0（群れから離れたくない力が存在する）
→ β_aniso > 1（前方の個体により強く追従する）
```

野生の馬の群れ逃避行動では、群れの先頭についていくことが生存に直結した。
サラブレッドは何百年も育種された「箱入り馬」だが、この本能がどの程度残存しているかはβ_cohesionの最適値で間接的に推定される。

もしβ_cohesion ≈ 0 に収束するなら、「群凝集本能はほぼ消失している」と解釈できる。
もしβ_cohesion > 0 に明確に収束するなら、「本能は残存しており、レース展開に影響している」。

**仮説2: 経験による学習**

```
→ β_experience < 1.0（出走回数が増えるとβ_cohesionが減衰する）
```

もしβ_experience ≈ 1.0なら「学習効果なし（本能は経験で変わらない）」。
もしβ_experience ≈ 0.95なら「20回出走で群凝集力が約6割に減衰（経験で合理化する）」。

**仮説3: 騎手の知性**

```
→ β_jockey > 0（騎手スキルが走行圧の回避能力に寄与する）
```

騎手は馬群の密度勾配 ∇ρ を感知し、低密度方向に馬を誘導する。
β_jockeyが大きいほど、上手い騎手と下手な騎手の差が着順に反映される。

### 7.5 最適化手法

5パラメータの最適化には以下を検討:
- **ベイズ最適化**: 5次元なら効率的に探索可能（100〜200回の評価で収束）
- **CMA-ES**: 進化戦略。5次元の連続最適化に適する
- **グリッドサーチ**: 5パラメータ×5段階 = 3,125通り。全探索も現実的

目的関数: シミュレーション結果の着順とNDCG@3の最大化

### 7.6 検証計画

```
学習: 中京芝1200m + 中山芝1200m + 阪神芝1200m（重賞、2012-2019）
      → 5パラメータを最適化

検証1: 高松宮記念 2012-2019（LOOCV、8回）
       → β の安定性と予測精度

検証2: 高松宮記念 2020-2021（ホールドアウト、2回）
       → 最終的な予測精度の評価

ベースライン比較:
  - 人気順（市場効率性）
  - β = 全て0（物理のみ、生物要素なし）
  - β = 最適値（フルモデル）
```

β=0（物理のみ）とβ=最適値（フルモデル）の予測精度の差が、
**生物学的仮説がレース予測にどれだけ貢献するか**の直接的な証拠になる。

### 7.7 note記事としての構成案

1. 「コースを帯に展開する」— 幾何学で距離差を可視化
2. 「芝は荒れる、坂は止める」— データで見えた物理効果
3. 「馬は群れたがるか？」— 生物学的仮説の導入
4. 「5つのパラメータに聞いてみた」— 学習結果の解釈
5. 「高松宮記念を物理で読む」— 予測と検証

→ 読者が段階的に理解でき、最後に「本能は残っていたのか？」の答えが出る構成。

## 8. モンテカルロシミュレーション（最終形態）

### 8.1 概要

物理モデルを確率的シミュレータとして運用する。
1回の決定論的予測ではなく、N=1000回の試行から各馬の着順確率分布を推定する。

### 8.2 入力パラメータ

```
固定パラメータ（レースごとに設定）:
  コース物理: 帯展開座標、坂プロファイル、R=300m
  学習済みβ: β_cohesion, β_aniso, β_experience, β_jockey, β_draft
  芝状態: C_turf(開催時期から推定)
  馬場状態: 良/稍重/重/不良 → 補正係数

馬ごとの初期パラメータ:
  能力値: 過去タイムから推定した基礎速度（m/s）
  脚質: 逃げ/先行/差し/追込 → ペース配分関数
  経験値: 通算出走回数 → β_experienceに適用
  当日体重: 馬体重増減 → 微小な能力補正

騎手ごとの初期パラメータ:
  β_jockey × 騎手スキル値: 過去成績から推定した走行圧感知能力

枠番:
  初期X位置: 枠番に応じたスタート時の横位置
```

### 8.3 確率的ゆらぎ（毎試行で変動）

| ゆらぎ要素 | 分布 | 物理的意味 |
|-----------|------|-----------|
| スタート反応 | N(0, 0.15²) 秒 | ゲート反応のばらつき |
| 当日コンディション | N(1.0, 0.02²) × 能力値 | 調子の良し悪し（±2%） |
| 馬群初期形成 | N(0, 1.0²) m | スタート直後の横位置ゆらぎ |
| 騎手判断ノイズ | N(0, σ²), σ = 0.1/skill | 騎手の判断ミス（上手い騎手ほど小さい） |
| 風向き | 全馬共通の微小ゆらぎ | 当日の風況 |

### 8.4 出力

1000回のシミュレーションから:

```
各馬の確率分布:
  P(1着), P(2着), P(3着), P(3着以内)
  着順の期待値 E[rank]
  着順の標準偏差 σ[rank]  ← 安定度の指標

レース全体の指標:
  荒れやすさ = 1 - max(P(1着))  ← 1着確率の最大値が低い = 混戦
  確実度 = P(3着以内)の上位3馬の合計 / 3

シナリオ分析:
  「枠番Xの馬がカーブでインに入れた試行: 600/1000回 → 3着以内率45%」
  「枠番Xの馬がカーブで包まれた試行: 400/1000回 → 3着以内率12%」
  → 位置取りの成否がどれだけ結果を左右するかを定量化
```

### 8.5 オッズとの比較（Model 3への接続）

```
モデル出力:  P_model(馬A 1着) = 15%
オッズ暗示: P_odds(馬A 1着) = 8%

乖離 = P_model - P_odds = +7%
→ 市場が過小評価している馬 = 期待値プラスの賭け候補

この乖離情報をModel 3（遺伝的アルゴリズム）に渡し、
最適な馬券組合せを探索する。
```

### 8.6 可視化イメージ

```
1. 確率バーチャート: 各馬の3着以内確率（横棒グラフ）
2. 着順ヒートマップ: 馬×着順の確率密度（色の濃さ）
3. 帯空間アニメーション: 1000回の軌跡をオーバーレイ → 「よく通る経路」が見える
4. シナリオツリー: 「先行馬がハイペース→差し馬有利」の条件付き確率
```

## 10. エネルギー枯渇モデル（直線逆転の物理）

### 10.1 重要発見: 中京1200mは「4角で決まらない」

4角TOP3がそのまま着順TOP3に入る率:
- 完全一致(3/3): **0.5%**（ほぼゼロ）
- 平均一致数: **1.00/3**
- 4角 vs 着順の相関: **r = 0.303**（他コースより低い）

比較: 阪神1200m(直線350m)はr=0.423, 完全一致8.2%。
**中京の直線412m+急坂が逆転を生む構造**を持つ。

### 10.2 核心データ: 前半ペース × 上り3Fのクロス分析

| 前半ペース | 上り3F | 平均着順 | 勝率 | 3着内率 | n |
|-----------|--------|---------|------|--------|---|
| **速い** | **速い** | **1.7** | **56.3%** | **90.3%** | 103 |
| 速い | 普通 | 4.4 | 12.1% | 44.1% | 456 |
| 速い | 遅い | 11.4 | 0.7% | 3.3% | 539 |
| 遅い | 速い | 8.3 | 4.3% | 14.4% | 605 |

→ **「前半速く走っても上りを維持できる」馬が圧倒的に強い**
→ これはエネルギー容量（E_max）の個体差として表現できる

### 10.3 先行馬のバテ分析

4角1-3番手にいた715頭のその後:
- 3着以内に残った: 29.7%（前半34.61s, 上り34.94s）
- 7着以下に沈んだ: **48.7%**（前半34.48s, 上り35.82s）
- **前半のペースはほぼ同じ（差0.13s）なのに、上りで0.87s差がつく**
- → バテるかどうかは前半のペースではなく**個体のエネルギー容量**で決まる

### 10.4 エネルギーモデルの運動方程式

各馬iのエネルギー残量:

```
E_i(t) = E_max_i - ∫₀ᵗ P_i(τ) dτ

  E_max_i: 馬iの最大エネルギー容量（個体パラメータ）
  P_i(t) = F_prop_i(t) × v_i(t): 瞬時消費パワー
```

エネルギー残量に応じた最高速度の減衰:

```
v_max_i(t) = v_base_i × g(E_i(t) / E_max_i)

  g(r) = 1.0        (r > 0.3)   ← 余裕あり、フルスピード可能
  g(r) = r / 0.3    (r ≤ 0.3)   ← エネルギー枯渇、速度低下
```

脚質による消費パターン:
- 逃げ馬: 前半でP大 → E(788m)が小 → 直線でg(r)が低下しやすい
- 差し馬: 前半でP小 → E(788m)が大 → 直線でg(r)を維持できる
- **勝てる逃げ馬 = E_maxが大きい馬**（前半飛ばしても直線で踏ん張れる）

### 10.5 推定方法

E_max_iは直接観測できないが、以下から間接推定可能:
- 同一馬の複数レースでの「前半タイム vs 上り3F」のパターン
- 上りの安定度（E_maxが大きい馬は上りのばらつきが小さいはず）
- 距離適性（1400m以上でも走れる馬はE_maxが大きい）
