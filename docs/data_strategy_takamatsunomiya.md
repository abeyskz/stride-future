# 📋 データ戦略: 高松宮記念ターゲット分析

> **STRIDE FUTURE - EDA Phase 2**
> **作成日**: 2026-02-22
> **対象レース**: 高松宮記念（中京・芝1200m・G1・3月下旬）

---

## 1. 問題の定義

### ターゲット
高松宮記念（中京芝1200m G1）の着順予測

### データ上の制約
- 2012年の中京新コース化以降、高松宮記念は**9回**しかない（2012-2021、データ範囲内）
- G1上位個体同士の実力伯仲した組合せは、このレース固有の性質
- 9件では学習データとして不十分

---

## 2. 解決方針: 階層的分離

物理モデルのパラメータを**コース特性**、**馬固有能力**、**組合せ効果**に分離し、それぞれ十分なデータプールから推定する。高松宮記念9回は「テストセット」として温存する。

```
予測 = f(コース特性, 馬能力, 騎手効果, 馬場状態, 組合せ効果)
         ↓            ↓          ↓          ↓          ↓
     中京1200m全203R  各馬全履歴  騎手全履歴  馬場物理   重賞対戦履歴
```

### 2.1 コース特性モデル（中京芝1200mから推定）

| 項目 | 値 |
|------|-----|
| 利用可能レース | 203レース（2012-2021） |
| 出走レコード | 3,313件 |
| クラス構成 | G1×10, G3(CBC賞)×9, G2×1, 一般戦×183 |
| 推定対象 | 坂の影響、コーナー曲率による減速、直線での加速特性 |

**ポイント**: コースの物理特性（坂、カーブ）はクラスに依存しない。一般戦のデータも使える。

### 2.2 馬固有能力モデル（各馬の全キャリアから推定）

| 項目 | 値 |
|------|-----|
| 高松宮記念出走ユニーク馬 | 127馬 |
| うち全出走レコード | 3,730件（平均29.4走/馬） |
| 距離分布 | 1200m: 1,807件, 1400m: 825件, 1600m: 719件 |
| グレード | G1: 559件, G2: 397件, G3: 908件, 一般: 1,794件 |

**ポイント**: 1馬あたり平均29回の出走データがある。異なる距離・コースでの走りから、馬固有の速度能力・持久力を推定可能。

### 2.3 組合せ効果モデル（スプリント重賞から推定）

| 項目 | 値 |
|------|-----|
| 対戦ペア総数 | 2,188ペア |
| 2回以上対戦 | 1,184ペア (54.1%) |
| 3回以上対戦 | 634ペア (29.0%) |
| 5回以上対戦 | 157ペア (7.2%) |
| 最多対戦 | 16回（ダイメイプリンセス vs ラブカンプー）|

**ポイント**: 過半数のペアが複数回対戦しており、相対的な力関係の推定に使える。

### 2.4 馬場状態（高松宮記念の特殊性）

| 年 | 馬場 | 勝ちタイム |
|----|------|-----------|
| 2012 | 良 | 1:10.3 |
| 2013 | 良 | 1:08.1 |
| 2014 | **不良** | **1:12.2** |
| 2015 | 稍重 | 1:08.5 |
| 2016 | 良 | 1:06.7 |
| 2017 | 稍重 | 1:08.7 |
| 2018 | 良 | 1:08.5 |
| 2019 | 良 | 1:07.3 |
| 2020 | **重** | 1:08.7 |
| 2021 | **重** | 1:09.2 |

3月下旬開催のため**馬場が荒れやすい**（10回中4回が稍重以上）。中京芝1200m全体では良馬場が74.9%だが、高松宮記念は良馬場が40%しかない。

## 3. かなたの懸念事項 🔍

### 懸念① 馬場状態の交絡が大きい

**問題**: 勝ちタイムの幅が1:06.7〜1:12.2（5.5秒差）。これは馬の実力差よりも馬場状態の影響が圧倒的に大きい。

**具体例**: 2016年ビッグアーサー(1:06.7, 良) vs 2014年コパノリチャード(1:12.2, 不良) → 5.5秒差だが、これは馬場の違いであり能力差ではない。

**対策**: タイムの絶対値ではなく、「同じレース内での相対的な着差」を使うべき。または馬場状態を明示的な共変量として物理モデルに組み込む。中京芝1200mの馬場状態別タイムデータ（203レース）から馬場補正係数を推定できる。

### 懸念② コース特性の推定にクラス間バイアスがある

**問題**: 一般戦とG1では出走馬の能力レンジが全く違う。一般戦のラップタイムプロファイルが、G1のハイレベルなペースで走る馬たちにそのまま適用できるか？

**具体例**: 一般戦の先頭馬は「逃げて粘る」パターンが多いが、G1では全馬が高速巡航するため、ペース配分の物理が異なる可能性。

**対策**: ラップタイムプロファイルをクラス別に層別化して比較する必要あり。少なくとも「重賞」と「一般戦」で分けて、コース特性の推定にバイアスがないか検証すべき。

### 懸念③ 対戦マトリクスの疎密問題

**問題**: 2回以上対戦が54.1%とはいえ、新しい世代の馬は過去の馬との対戦がゼロ。年度をまたぐ対戦データは急速に減る。

**具体例**: 2021年の高松宮記念出走馬は、2012年の出走馬とは対戦経験がない。「共通対戦相手を介した間接比較」に頼らざるを得ないが、推定の不確実性が増す。

**対策**: Eloレーティング的な「時間減衰つき能力推定」を検討。または、対戦マトリクスではなく、各馬の独立した能力推定値同士を比較する方式にする（Stokes et al.の馬固有ランダム効果に近い）。

### 懸念④ 高松宮記念のタイム分散が示す「荒れやすさ」

**問題**: 9回中、人気通りの決着（1-2-3番人気が3着以内）は少ない。

| 年 | 1着人気 | 2着人気 | 3着人気 | 荒れ度 |
|----|---------|---------|---------|--------|
| 2012 | 2 | 3 | 1 | 低 |
| 2013 | 1 | 2 | **10** | 中 |
| 2014 | 3 | **8** | 1 | 中 |
| 2015 | 4 | **6** | 3 | 中 |
| 2016 | 1 | 2 | 3 | **低** |
| 2017 | **5** | 2 | 1 | 中 |
| 2018 | 2 | 3 | **10** | 中 |
| 2019 | 3 | **12** | **17** | **高** |
| 2020 | **9** | 2 | 4 | 中 |
| 2021 | 2 | 1 | 3 | 低 |

→ 完全に人気通りなのは2016年のみ。これはスプリントG1の本質的な予測困難性を示している。18頭のフルゲート、実力伯仲、展開次第…。

**示唆**: モデルの目標を「1着を当てる」ではなく「上位3頭を高確率で含む予測」(NDCG@3)に設定するのは正しい判断。ただし、人気順ベースラインすら安定して3着以内に入れない現実を認識しておく必要がある。

### 懸念⑤ データの時間的制約

**問題**: データは2021年7月で終了。2022年以降のデータがない。

**影響**:
- 最新のトレンド（種牡馬の世代交代、調教法の変化）を反映できない
- 2025年の高松宮記念を予測する場合、3-4年のギャップがある
- ただしnote記事としては「方法論の提示」が目的なので、2021年データでの検証は十分に価値がある

**対策**: 記事では「2012-2020の8回で学習、2021年を予測」というバックテスト形式で検証するのが現実的。

## 4. 推奨するモデル学習/検証の分割

```
学習データ:
  コース特性  → 中京芝1200m 一般戦+重賞 (2012-2020, ~180レース)
  馬能力      → 各馬の全出走履歴 (~2020年末まで)
  組合せ効果  → スプリント重賞全体 (2012-2020)
  馬場補正    → 中京芝1200m全レース (2012-2020)

検証データ:
  高松宮記念 2012-2019 (8回) → クロスバリデーション（LOOCV）
  高松宮記念 2020-2021 (2回) → 最終ホールドアウトテスト
```
